# Privacy Compass public catalog

This repository publishes reviewed Privacy Compass profiles and bare application identity records from the private Android development repository. Identity-only records contain no privacy assessment and compatible clients label them "Recognized — research pending." It contains declarative JSON only. No Android source, credentials, signing keys, personal inventories, benchmarks, or migration progress are published.

The private repository remains the source of truth. Each publication must be generated and reviewed before the public copy is updated. The manifest records schema, version, date, size, and SHA-256 checksums.
