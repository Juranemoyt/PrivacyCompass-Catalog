# Privacy Compass public catalog

This repository is a published copy of reviewed catalog data from the private Privacy Compass Android development repository. It contains declarative JSON only. No Android source, credentials, signing keys, personal inventories, benchmarks, or migration progress are published.

The private repository remains the source of truth. Each publication must be generated and reviewed before the public copy is updated. The manifest records schema, version, date, size, and SHA-256 checksums.
